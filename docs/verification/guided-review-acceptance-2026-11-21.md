## Verified causes and scoped fixes

- Entry used a saved preference/session to bypass the chooser. Fresh top-level entry now gates candidate preparation behind explicit Resume or a new mode choice. Resume shows actual mode/status; new review preserves old workflows and per-review drafts. In-review navigation does not reopen the gate. Apply/rollback transition and recovered operation results take priority over entry choice.
- Validation closed summary and used toolbar state without a blocking operation result. Shared validation/Apply flow now provides a native accessible modal, real count, dashboard inertness, duplicate prevention, focus handling, truthful result and explicit next action. No invented progress stages. Reduced motion is respected.
- Summary was a static snapshot. It now rerenders against current validation, freshness, decisions and operation state, retaining focus where possible. Passed validation offers Apply; changed composition explains invalidation.
- Apply used generic confirmation. Product confirmation lists the actual project root, affected accepted file paths, validated count, excluded states and receipt-backed protected recovery. Cancel does not write. Apply progress/result requires authoritative server success.
- A disconnected mutation had no durable client/server operation identity. Server journals bounded operation IDs before mutation, returns the same record for repeated IDs and rejects overlapping unresolved mutations. Client reconciles exact workflow/operation state after loss or reload; it never assumes a timeout means success or non-execution.
- Applied workflow and refreshed scan were displayed together without context. Historical Applied/validation labels, Current source labels, operation details and Start review of remaining findings now distinguish them. New remaining review has no inherited Accepted decisions or validation.
- Remaining Deferred decisions were lost when source-offset IDs changed after earlier patches. Receipt-verified transition now carries only uniquely matched unchanged non-Accepted decisions/notes, using path/rule/context/mechanism/original slice plus exact patch-derived offset. Ambiguous or changed source requires new review; historical workflow stays accessible. Unit and installed browser checks prove Deferred carry after an offset shift.
- `.unmapped` is a rendered intentional negative fixture, deliberately absent from page/element bindings. It remains unmapped regression coverage; no borrowed mapping or CSS edits. UI explains the limitation and evidence needed; remaining review permits Defer/Needs review while approval stays disabled without a prepared eligible target. Existing bulk code preparation does not substitute for required direction evidence at validation/Apply.

Two additional defects found during browser verification were fixed: open summary actions could remain disabled after preview finished, and recovered results could remain hidden behind the entry screen. Narrow Apply dialogs now wrap long real paths within the viewport.
